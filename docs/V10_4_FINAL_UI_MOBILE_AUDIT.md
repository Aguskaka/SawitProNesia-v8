# SawitProNesia v10.4 — Final UI & Mobile Audit

Patch ini memoles pengalaman lintas aplikasi tanpa mengubah schema database atau logic bisnis.

## Perubahan utama
- Sidebar desktop kini memakai active state berdasarkan route aktual.
- Brand mark memakai ikon SVG konsisten, bukan emoji.
- Loading state menjadi skeleton dashboard dan error state lebih informatif.
- Tap target, focus state, form input, safe-area, dan overflow mobile diperkuat.
- Table/panel generik dibuat lebih aman pada layar sempit.
- Mobile form menggunakan ukuran font 16px untuk menghindari auto-zoom browser.
- Dukungan reduced-motion ditambahkan untuk aksesibilitas.
- Version marker dinaikkan ke v10.4.

## Database
Tidak ada migration atau perubahan schema Supabase.
