# SawitProNesia v9.7 — Pupuk & Pemupukan Premium UI

## Scope
- Redesain halaman `/pupuk` menjadi fertilizer control center.
- Ringkasan kebutuhan material, realisasi, sisa, estimasi dan biaya aktual.
- Program board untuk status Terjadwal / Sebagian / Selesai.
- Form program existing dipertahankan dan ditempatkan pada workflow yang lebih jelas.
- Acuan dosis TBM/TM tetap tersedia tanpa mendominasi layar utama.
- Redesain detail program `/pupuk/[programId]` dengan progress ring, KPI, dose table, form realisasi dan execution history.
- Realisasi tetap menggunakan action existing dan tetap otomatis membuat operation Pemupukan.
- Tidak ada migration database pada v9.7.
- Version marker dinaikkan ke v9.7.
