# SawitProNesia v9.3 — Home & Owner Command Center Final

Baseline: v9.2.3.

Home dipertahankan sebagai satu calculation surface dengan modul Laporan/Analytics dan difinalkan sebagai owner command center mobile-first:
- Hero status kebun + kebun aktif/tahun.
- KPI produksi, pendapatan, biaya, margin, budget.
- Perlu Perhatian dari status Rencana/Kalender.
- Agenda berikutnya.
- Budget usage, produksi per blok, tren pendapatan vs biaya.
- Progress pemupukan.
- Owner Insight.
- Aktivitas terakhir.
- Aksi cepat: Rencana, Aktivitas, Panen, Tenaga, Laporan, Analytics.
- Mobile bottom navigation tetap ringkas; Laporan/Analytics berada di Aksi Cepat, bukan menambah bottom-nav.
