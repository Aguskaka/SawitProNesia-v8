# SawitProNesia v8.3 — Aktivitas

## Scope
Native Next.js operational activity module using the existing `operations` table.

Implemented:
- `/aktivitas`
- `/aktivitas/[operationId]`
- Active Estate + Global Year context
- Actual activity history
- Direct activity create/edit/delete
- Central cost calculation:
  `(quantity × unit_price) + (labor_days × labor_rate)`
- Estate/block linkage
- Worker/mandor, note, dose-per-tree
- Category filters
- DIRECT vs PROGRAM distinction

## Integrity rule
Generic Aktivitas may edit/delete only operations where:
- `source = DIRECT`
- `plan_id IS NULL`
- `fertilizer_program_id IS NULL`

Operations generated by Plan/Fertilizer remain visible but read-only here.
They must later be changed from their source module so Plan → Actual integrity is preserved.

## Not migrated in v8.3
- Harvest/Panen CRUD
- Fertilizer Program CRUD
- Plan/Realisasi CRUD
- Activities audit-log table UI

No Supabase SQL migration is required.
