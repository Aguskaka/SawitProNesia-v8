# SawitProNesia v10.2 — Management Report Center

Pembaruan modul Laporan menjadi Management Report Center.

## Cakupan
- Ringkasan produksi, pendapatan, biaya dan margin operasional.
- Produktivitas ton/Ha, BJR, harga rata-rata TBS dan biaya produksi/Kg.
- HOK, pemupukan aktual, jumlah aktivitas dan biaya/Ha.
- Trend pendapatan vs biaya bulanan.
- Struktur biaya aktual dan rekonsiliasi bulanan.
- Kinerja per blok.
- Cetak / Save as PDF melalui browser.
- Export CSV tanpa library tambahan.

## Data
Semua KPI bersumber dari tabel yang sudah ada: estates, blocks, harvests, operations, annual_budgets. Tidak ada migration database.
